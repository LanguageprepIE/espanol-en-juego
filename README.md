# TY Spanish · Conversation Challenge

Juego proyectable de conversaciones guiadas creado para las clases de TY Spanish del Sr. Martín.

## Publicación en GitHub Pages

Sube todo el contenido de la carpeta `dist` a la raíz del repositorio. Después activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main / root**.

No necesita servidor, base de datos, cuentas ni claves. Los puntos solo existen durante la partida y se borran al iniciar una nueva.

## Contenido

- Conocer a alguien: conversaciones A, B y C (60 rondas)
- Un día en el instituto: conversaciones A, B y C (60 rondas)
- Selector de conversación concreta o aleatoria

Las conversaciones A están en `data/conversations.json`. Las variantes B y C están en `data/variants.json`.

## Español en juego: aventuras de plataformas

The homepage also links to `aventuras/`, a selection page for School Escape and AYER: El misterio de la mochila (regular/irregular preterite, Junior Cycle). AYER is implemented in `aventuras/ayer/` with its own four maps, original art, verb notebook and local Mission Report. School Escape retains its existing public URL for the Friday lesson.

The site is served from this repository root on GitHub Pages. New adventures can be added as separate folders under `aventuras/`; add a card to the selection page when an adventure is ready.

## La maleta de noviembre — misión cultural TY

Actividad autónoma por parejas en `maleta-de-noviembre/`, accesible desde la portada. Incluye cuatro misiones de vocabulario y comprensión, una visita guiada con tres fotos reales de Tosantos (con fuentes y créditos), un taller de calaveras por números integrado en el recorrido y una tarea creativa con modelo ilustrado, frases guiadas e informe descargable para Teams. Duración orientativa: 40–50 minutos.

No requiere registro ni backend. El progreso se guarda en el navegador; para una pareja nueva, guardar primero el informe y usar la opción de reiniciar. Las fotos se sirven con la actividad. El acceso «Español en juego» permite volver al catálogo.

### Taller visual de Tosantos

La misión final incluye un puesto vacío original en SVG y 29 piezas reutilizables de comida, ropa y objetos. Arrastrar desde la paleta o pulsar para añadir; mover, girar, redimensionar, invertir, duplicar, cambiar de capa, borrar y deshacer. Admite ratón, táctil y controles de teclado. El puesto se guarda localmente y se exporta como PNG; el informe impreso/PDF incluye la escena. La descripción en español pasa a ser opcional. Para terminar se pide un título, al menos un alimento y una prenda, además de las tres reflexiones culturales.
